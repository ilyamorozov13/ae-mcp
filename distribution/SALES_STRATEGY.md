# AE-MCP Pro Sales & Pricing Strategy

## Pricing Tiers

### 1. Basic License - $79
**Target:** Freelancers, hobbyists, small creators
- Single user license
- Core functionality
- Email support (48h response)
- Basic examples and documentation
- 1 year of updates

### 2. Pro License - $149 (Most Popular)
**Target:** Professional motion designers, small studios
- Single user license
- All features + advanced capabilities
- Priority support (24h response)
- Video tutorial series (10+ hours)
- Expression preset library (50+ presets)
- Advanced workflow examples
- Discord community access
- 1 year of updates

### 3. Team License - $399
**Target:** Studios, agencies, production companies
- 5 seat license
- Everything in Pro
- Private Discord channel
- 1-on-1 onboarding call
- Custom workflow consultation
- Invoice/PO payment options
- 1 year of updates

### 4. Enterprise License - Custom
**Target:** Large studios, broadcasters
- Unlimited seats
- Source code access
- Custom feature development
- SLA support
- Training sessions

## Sales Channels

### Primary: Gumroad
**Pros:**
- Easy setup and management
- Built-in licensing system
- Handles payments and taxes
- Affiliate program
- Analytics dashboard

**Setup:**
1. Create product variants for each tier
2. Use Gumroad's license key generation
3. Set up automated email delivery
4. Configure discount codes

- Own website with Stripe/PayPal
- More control, lower fees
- Better for enterprise deals
